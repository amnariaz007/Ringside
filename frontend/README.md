# Ringside dashboard

React 19 + Vite + TypeScript + React Flow. In development it proxies `/api` to the Django backend on port 8000.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # type-check + production build into dist/
```

See [../docs/IMPLEMENTATION.md](../docs/IMPLEMENTATION.md) for the pages and the API they use.

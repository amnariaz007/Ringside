# Ringside brand

The mark is a **ring of five connected accounts with one flagged in red**. That's what Ringside does: it finds fraud rings among a seller's buyers and flags the risky account before the order ships.

| File | Use |
|---|---|
| `ringside-mark.svg` | App icon, favicon, avatars (Devpost thumbnail, GitHub social preview) |
| `ringside-mark-512.png`, `ringside-mark-1024.png` | The same mark as an image, for uploads that don't accept SVG |
| `ringside-logo-light.svg` / `.png` | Full logo for **light** backgrounds (README, slides) |
| `ringside-logo-dark.svg` / `.png` | Full logo for **dark** backgrounds (white text, transparent background) |

## Colours

| Name | Hex | Where |
|---|---|---|
| Ringside blue | `#1f5eff` | Icon background, links, active states |
| Flag red | `#ff5a4e` | The flagged node (the only red in the mark) |
| Ink | `#15181e` | Wordmark on light backgrounds |
| White | `#ffffff` | Nodes; wordmark on dark backgrounds |

## Rules

- Keep the mark's rounded square; don't place the bare ring on blue backgrounds.
- Leave clear space of at least a quarter of the icon's width around the logo.
- The wordmark in the SVG files uses the system UI font (SF Pro on Mac, Segoe UI on Windows). The **PNG files are the fixed version**: use them anywhere the look must be identical, such as Devpost, YouTube and slides.
